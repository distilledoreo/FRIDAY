## Grounded public research checkpoint — 0.14.0

0.14.0 code18 routes the phone's web search and page tools through authenticated, stateless `/grounding` endpoints. Public HTTPS reads pin validated DNS addresses, revalidate redirects, reject private destinations and caller credentials, and accept only bounded static HTML/plain text. Search keeps up to ten results and reads at most three pages. It selects up to three exact query-matching passages throughout each bounded 100,000-character document, including text beyond the opening section, with offsets, normalized-document SHA-256, check time, publisher date metadata and truncation labels. No matches produce no supporting passages. Evidence is capped at 24,000 UTF-8 bytes. Snippet-only, unavailable and retrieved sources remain distinct. Publisher dates and source text are untrusted; retrieval does not prove truth.

A shared host pool limits phone and approved-agent page reads to three actual workers. Canceled or timed-out readers occupy capacity until their threads finish. The reader checks a 45-second deadline between redirects/body chunks and uses 15-second socket timeouts. OS DNS resolution and slowly arriving response headers can outlast the caller deadline; these workers remain tracked rather than silently releasing capacity. Health exposes pending reads and the idle deployment guard checks them. These new phone tools have no fallback to the legacy `/search` or `/fetch` routes, which remain present for compatibility.

Chat's English CPU trigger covers explicit source reads and research/current information, respects no-search instructions, and skips recognized private account/credential requests. This is a heuristic, not a complete semantic privacy detector. Automatic retrieval sends only the user's current typed public query, never appended private snapshots or recalled context. Once prior private tool data or recalled memory is present, model-initiated public search/page calls require separate confirmation of the exact query or URL; private reads and web calls in one tool batch also require that confirmation. A no-search turn removes and rejects public web calls. Citation status checks whether links match retrieved passage sources; it does not judge factual support or truth. Prompts require checking material claims against passages, primary authority, dates, conflicts and uncertainty. These instructions were not evaluated with real inference during the embargo.

For eligible public research questions, Propose deeper research in Activity saves a reviewable plan, never approves or starts it. Approved public-agent reads now accept an optional topic and return the same passage provenance, including later sections; screenshots still use the exact fetched static HTML with external resources/JavaScript disabled. Private account-scoped cloud tasks still cannot use public web tools. Agent audit stores passage offsets/digests, not copied source bodies.
